    Tabular Exporter

    Abstract tabular exporter — shared logic for Excel and CSV.

    Author: Clement RACINET

    This module factors out the construction of the four DataFrames (traj, tools, wobjs, meta) into :class:_TabularExporter.

    Subclasses only need to implement one method: :meth:_write_sheets, which receives the ready-to-write DataFrames and writes the output file(s).

    Architecture

    ::

    BaseExporter (ABC)
    └── _TabularExporter (ABC)
            ├── ExcelExporter   → _write_sheets() via openpyxl
            └── CsvExporter     → _write_sheets() via 4 CSV files

    Import / export symmetry

    The exported traj sheet is the exact mirror of the imported sheet:

    • tool_index and wobj_index are resolved to names (tool and wobj columns).
    • Floats are rounded according to :attr:~trajcenter.exporter.options.ExportOptions.float_precision.
    • The meta sheet is produced in key/value format, re-readable at import time.
