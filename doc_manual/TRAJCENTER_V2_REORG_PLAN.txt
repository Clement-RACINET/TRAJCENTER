TRAJCENTER V2 - REORGANIZATION PLAN
===================================

Goal
----

Reorganize TrajCenter v2 into clear modules:

- core trajectory model and validation
- file conversion
- file export
- robot communication
- CLI / terminal interface
- RAPID controller-side files

Keep one repository.
Make robot communication optional.
Keep file conversion usable without robot dependencies.

Python packages
---------------

trajcenter.core
  Shared trajectory model, validation, messages and logging.

trajcenter.convert
  File import/conversion API.
  Must not depend on robot/RWS code.

trajcenter.export
  File export API.
  Must not depend on robot/RWS code.

trajcenter.robot.abb
  ABB robot communication API.
  RWS reader, writer, resolver, supervisor and errors.

trajcenter.rws
  Temporary compatibility package during migration.

trajcenter.cli
  Command line interface.

trajcenter.ui
  Optional terminal UI.


Install profiles
----------------

Base install:

  pip install trajcenter

Development install:

  pip install -e .

Robot option:

  pip install "trajcenter[robot]"

CLI option:

  pip install "trajcenter[cli]"

TUI option:

  pip install "trajcenter[tui]"

Full option:

  pip install "trajcenter[all]"

RAPID rules
-----------

- ASCII only.
- Function, variable and constant names below 30 characters.
- Keep RAPID files synchronized with Python robot API.
