Constants¶

trajcenter.robot.constants ¶

Python-side defaults and expected TrajCenter ABB protocol constants.

Author: Clement RACINET

The live RAPID controller remains authoritative for deployed array capacities and cell configuration. Constants in this module define the protocol profile supported by this Python package and provide offline defaults.

ABB Route

N/A - local constants only.

ABB Constraints

Values mirror the RAPID declarations in TRAJCENTER sys module

Example 
from trajcenter.robot.constants import MAX_TRAJ_POINTS

assert MAX_TRAJ_POINTS == 100000
