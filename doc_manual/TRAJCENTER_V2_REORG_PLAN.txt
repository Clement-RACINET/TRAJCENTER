TRAJCENTER V2 - REORGANIZATION PLAN
===================================

Goal
----

Reorganize TrajCenter v2 into clear modules:

- core trajectory model and validation
- file conversion
- file export
- ABB robot communication
- CLI / terminal interface
- RAPID controller-side files

Keep one repository.
Make robot communication optional.
Keep conversion/export usable without robot dependencies.


Branches
--------

Base branch:

  v2

Work branch:

  v2-modular-architecture

Merge target:

  v2-modular-architecture -> v2


Current rules
-------------

- Do not edit trajcenter/__init__.py manually.
  It is generated by py-init-tools.

- Do not reorganize the documentation yet.
  docs/ is used by MkDocs and generated API/coverage files.
  doc_manual/ can stay temporarily.

- Do not move RWS implementation yet.
  trajcenter/rws remains the active implementation during migration.

- scripts/run_rws_supervisor.py is an operational launch script.
  It is not an example script.
  It may later be replaced or wrapped by:
    trajcenter robot supervise

Python packages
---------------

trajcenter.core
  Shared trajectory model, validation, messages and logging.

trajcenter.convert
  New public conversion API.
  Must not depend on robot/RWS code.

trajcenter.converter
  Current conversion implementation.
  Kept temporarily for compatibility.

trajcenter.export
  New public export API.
  Must not depend on robot/RWS code.

trajcenter.exporter
  Current export implementation.
  Kept temporarily for compatibility.

trajcenter.robot.abb
  Future ABB robot communication API.

trajcenter.rws
  Current ABB RWS implementation.
  Kept active during migration.

trajcenter.cli
  Command line interface.

trajcenter.ui
  Future terminal UI.


Install profiles
----------------

Base install:

  pip install trajcenter

Robot option:

  pip install "trajcenter[robot]"

CLI option:

  pip install "trajcenter[cli]"

TUI option:

  pip install "trajcenter[tui]"

Full option:

  pip install "trajcenter[all]"
